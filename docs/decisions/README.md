# Decision log

One entry per decision that could reasonably have gone another way: what was decided, why, and when. Entries are appended, never rewritten; a reversed decision gets a new entry that points back to the old one. Organisation-wide decisions (naming, regions, budgets, tooling) live in the `portfolio` repository's `docs/decision-log.md`; this file holds the decisions specific to this repository.
